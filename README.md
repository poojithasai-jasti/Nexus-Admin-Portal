Nexus Admin Portal
A custom admin management system built with Flask and SQLAlchemy.

How to Run
1. Install dependencies: pip install -r requirements.txt

2. Run the application: python app.py

3. Access the portal at: [http://127.0.0.1:8080](http://127.0.0.1:8080)

Key Features
1. Secure Login & Signup.

2. 1-Hour Security Token for password resets.

3. Dynamic Dashboard using AJAX for real-time updates.
